# Task

Read and follow the [Task section of AGENTS.md](../../AGENTS.md#task).
Use `$ARGUMENTS` to identify the feature and requested task scope. Without task
IDs, select the next ready task; continue the whole feature only when requested.
An explain/assess-only request stays read-only.
